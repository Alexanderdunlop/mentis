React adapter useMentis + useMentionQuery

The same engine as the inspector, driven by React instead of by dev/main.ts. Type @al to open the menu; arrows move, Enter or Tab inserts, Escape dismisses.

What this is proving: the whole adapter is two hooks and a ref. React never renders into the editor — it renders an empty div and the engine owns the children from there. The mention menu is a useMemo over derived state, not a piece of React state, so there is no open/closed flag that can go stale (ADR 0006), and the keyboard handling is the consumer's because the engine only ever intercepts beforeinput (ADR 0003).
