Editor

The engine owns beforeinput; the DOM is a projection of the model. Caret movement is still the browser's. Uncheck engine attached to fall back to a bare contenteditable and compare — the Model panel goes empty when detached.

IME: during composition the engine deliberately hands the DOM to the browser, then reconciles on compositionend — watch composing in the Model panel flip, and the composition events in the log. History

⌘Z / ⌘⇧Z (or Ctrl+Y) work in the editor. Native undo is gone — the engine prevents every beforeinput, so the browser's own stack is empty. A run of typing is one step; a pause, a newline, or switching to deleting starts another.
